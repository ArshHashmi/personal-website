Overview

What this project is

I built AVIWS — the Active Variable Incidence Wing System — from scratch in under two weeks. It's a fully autonomous rear wing that adjusts its angle of incidence in real time based on vehicle acceleration. No driver input, no external vehicle integration — entirely self-contained.

Three modes handle the full range of a driving cycle. Under acceleration the wing flattens to shed drag — the same principle as F1's DRS. At cruise it holds a shallow angle for an efficient downforce-to-drag ratio. Under braking it deploys as a full airbrake to supplement the car's own brakes.

It's rooted in two real precedents: the variable-incidence wing of the Vought F-8 Crusader — the only production aircraft to ever implement the concept — and the active lateral aero system of the Zenvo TSR-1.

The build covers the full process: a custom cambered airfoil designed in Fusion 360, CFD validation across all three modes in Autodesk CFD, 15+ FDM-printed components across a modular 1400 mm span assembly, embedded C++ firmware on an Arduino Nano with a moving-average IMU filter and debounce control logic, and full on-car validation on my own car.

How It Works

Three modes, fully autonomous

An onboard IMU reads vehicle acceleration continuously. A moving-average filter smooths the signal, and debounce logic decides which mode the wing should be in — then holds it there until the driving state genuinely changes, so it doesn't hunt back and forth at the boundary.

Acceleration −5° Angle of incidence

Flattens to shed drag and maximize straight-line performance — the same principle as F1's DRS.

Build Process

Phase by phase

01
Phase 1 — Concept & Inspiration Done
Two real precedents, one autonomous system
  • Studied the Vought F-8 Crusader's variable-incidence wing — the only production aircraft to use the concept
  • Looked at the Zenvo TSR-1's active lateral aero system as a second reference point
  • Defined the three-mode behavior: flatten under acceleration, hold at cruise, deploy under braking
  • Set target angles of −5°, +5°, and 40° for each mode
02
Phase 2 — Airfoil & CAD Done
Custom cambered airfoil, modeled in Fusion 360
  • Designed a custom cambered airfoil profile from scratch
  • Split the 1,400 mm span across 15+ individually printable components
  • Modeled the servo, trunk-mount bracket, and linkage arms as one assembly
  • Ran motion studies on the linkage to validate the −5° to 40° actuation range
03
Phase 3 — CFD Validation Done
Autodesk CFD across all three modes
  • Simulated flow at each mode's incidence angle — acceleration, cruise, and braking
  • Extracted the drag and downforce figures used to size the control logic thresholds
  • Streamline and velocity-magnitude visualizations informed the final geometry
04
Phase 4 — Fabrication Done
15+ FDM-printed components, assembled into one wing
  • Printed and assembled every wing segment, mount, and linkage arm
  • Mounted to the trunk lid via a custom printed bracket
  • Routed wiring for the IMU, servo, and control electronics
05
Phase 5 — Firmware & Electronics Done
Arduino Nano running embedded C++
  • Moving-average filter smooths raw IMU acceleration readings
  • Debounce logic decides mode transitions so the wing doesn't hunt at the boundary
  • Entirely self-contained — no vehicle ECU integration, no driver input
06
Phase 6 — On-Car Validation Done
Tested on my own car, in real driving conditions
  • Confirmed autonomous mode-switching under real acceleration and braking events
  • Logged heading and speed alongside wing behavior to verify timing
  • Validated the CFD-predicted drag and downforce figures held up on-car
07
Phase 7 — V2 Redesign In Progress
Rebuilding for durability
  • Revisiting mounts and printed components for a more durable second version
