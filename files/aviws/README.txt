Drop the AVIWS part files in this folder. The guide links to these exact names:

  aviws-parts.zip           everything below, in one archive
  wing-centre-section.stl   200 mm constant-profile centre section
  wing-tip.stl              250 mm lofted outboard section
  endplate.stl              wingtip plate with the M3 insert pockets
  support-bracket.stl       upright with the servo pocket and hinge bore
  servo-horn.stl            DS3218 spline horn
  connecting-arm.stl        horn to wing link (print in CF-PLA)

Any file that is not here yet will show as "file not uploaded yet" on the
guide instead of handing someone a broken download. Add the file and the
card turns into a working link on its own; nothing else needs changing.

STEP files can sit alongside the STLs with the same base name.
